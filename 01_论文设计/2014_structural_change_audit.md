# 2014 年银川市人间布鲁氏菌病结构变化审计

**版本：P0 v1.0**  
**审计日期：2026-09-21**  
**用途：正式 ITS/SAP 前的资料审计；不用于生成政策效果结论。**

## 1. 审计问题

银川市报告病例由 2013 年 168 例增至 2014 年 461 例，增幅约 174%。本审计回答：

1. 2014 年是否存在布病诊断标准变化；
2. 是否存在全国/银川网络直报规则变化；
3. 是否存在银川布病主动筛查政策变化；
4. 是否存在实验室检测能力重大变化；
5. 是否存在银川或宁夏畜牧业扩张证据；
6. 是否存在同期宁夏整体布病上升。

## 2. 数据事实

仓库已核对年度序列显示：

- 2012：58 例
- 2013：168 例
- 2014：461 例
- 2015：483 例
- 2016：378 例
- 2017：299 例
- 2018：317 例

来源：`01_论文设计/银川市年度发病率序列_已核对.csv`。

因此，2014 年确有明显水平跃升；2015 年仍处于高位，之后回落。

## 3. 逐项审计

### 3.1 诊断标准变化：**已证实——2014 年没有发生国家布病诊断标准切换**

- WS 269—2007《布鲁氏菌病诊断标准》发布时间 2007-04-17，实施时间 2007-10-15。
- WS 269—2019《布鲁氏菌病诊断》发布时间 2019-01-02，实施时间 2019-07-01，并替代 WS 269—2007。

因此，2014 年仍处于 WS 269—2007 的连续适用期，未发现国家诊断标准在 2014 年发生切换。

**证据等级：已证实事实。**

### 3.2 网络直报/报告管理规则：**支持性证据——未发现 2014 年全国性报告规范切换**

- 全国传染病与突发公共卫生事件监测信息报告系统自 2004 年上线。
- 2006 年版《传染病信息报告管理规范》在 2014 年仍有效。
- 《传染病信息报告管理规范（2015年版）》于 2015-11-11 发布，自 2016-01-01 起执行，同时废止 2006 年版。

因此，未发现恰在 2014 年生效的全国传染病信息报告管理规范替换。

但公开资料不足以排除银川市内部在 2014 年存在局部软件升级、审核流程调整、培训强化或报告质量提升。

**证据等级：支持性证据；不能证明“2014 年绝无本地报告机制变化”。**

### 3.3 主动筛查政策：**未找到证据**

在当前仓库及本次政府/官方公开资料检索中，未找到明确证据表明银川市于 2014 年新启动了一个足以解释病例跃升的全市布病高危人群主动筛查项目。

这表示“目前没有找到”，不等于证明“没有发生”。

**证据等级：未找到证据。**

### 3.4 实验室检测能力重大变化：**未找到证据**

当前仓库和公开资料未找到 2014 年银川市布病实验室检测能力突然扩容、检测方法集中切换或定点实验室新增等能够明确解释 2013→2014 跃升的资料。

**证据等级：未找到证据。**

### 3.5 畜牧业扩张：**存在区域背景支持，但不足以解释银川 2014 单一断点**

仓库 `畜牧业生产情况_2013-2024.xlsx` 实际可用数据自 2014 年起，缺少 2013 年同口径数据，因此不能仅靠仓库内部数据直接证明“2013→2014 牛羊存栏骤增”。

已发表宁夏研究显示：
- 2012–2015 年宁夏人间布病发病率逐年上升；
- 2015 年达到阶段高点，2015–2018 年下降；
- 人间布病发病率与羊存栏数呈正相关（Spearman r=0.692，P=0.000）。

因此，“前期畜牧业发展/羊群暴露增加造成传染源累积”具有区域层面的生物学与流行病学合理性，但不能作为银川市 2014 年病例跃升的已证实原因。

**证据等级：支持性证据 + 合理假说。**

### 3.6 同期宁夏整体疫情上升：**已证实的区域背景**

已发表研究明确显示宁夏 2012–2015 年人间布病发病率逐年增加，说明银川 2014 年的跃升发生在自治区整体上升周期内，而非一个完全孤立的市级异常。

**证据等级：已证实区域背景。**

## 4. 结论

> **2014 年结构变化原因尚不能由现有资料确定；区域疫情上升和畜牧暴露增加可作为可能背景机制，但不得作为已证实原因。**

现有证据可进一步排除一个重要解释：**2014 年跃升不是由国家布病诊断标准在该年切换所直接造成。** 同时，国家传染病信息报告管理规范也未在 2014 年发生替换。

但不能排除银川本地未公开的主动筛查、实验室能力、报告质量或动物疫情变化。

## 5. 对 SAP 的处理建议

本审计不要求继续寻找一个“唯一原因”后才能建模。建议：

1. 主 ITS 建模窗口从 **2014-01** 开始；
2. 2004–2013 作为长期描述背景；
3. 敏感性分析纳入 2013 年，并显式设置 **2014-01 structural shift**；
4. 不在正文中把“畜牧业扩张导致 2014 暴发”写成确定事实；
5. 若后续找到 2014 年银川疾控/卫健内部工作总结，再更新本审计，不追溯修改既有原始数据。
