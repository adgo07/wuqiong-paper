3. **时间维度两档窗口（v3.0 定稿：W-A / W-B；W-C 已随 M9/M10 删除而取消）**：
   - **W-A 全景窗 2004–2025**（22 年）→ A1 描述

   - **红线**：同一模型内暴露与结局必须同频（保留原则；v3.0 下仅 B2 相关，用时不变横截面不构成错配）
   - **推断阶梯（v3.0 简化为三档）**：L1 因果（A2/A3）· L2 一致性（B1/B2）· L3 描述（A1/C）。**结论句措辞不得越级**

   - 处理原则：**分层窗口策略**——不同窗口不造出不同数据，只造出不同估计；要求不是"窗口一致"而是"**估计对窗口选择稳健**"

4. **空间口径**：「银川市区」= 兴庆区 + 金凤区 + 西夏区；旧气象表仅 4 个区域（银川市区/永宁/贺兰/灵武）。**v2.2 新增全市逐日气象表后，空间错分风险已定量降级**：4 区域年均气温极差仅 1.03℃、与全市序列 r≥0.997；**但风速空间代表性差（贺兰 r=0.115），只用于全市尺度**。畜牧业 2019 年用「银川市区」聚合行，2020 起才拆单区。

5. **气象数据处理规则（写入 Methods）**：主序列用新表日值聚合到周/月；**降水 NaN 视为 0 mm**（重叠期偏差 ≈0 已验证）；**弃用**最大湿度与霾日；日照/能见度窗口取 2015–2025；衍生日温差 DTR；无需插补；旧 4 区域月表降级为空间敏感性分析。

## 三、数据质量红线（分析前必须处理）

- 人口分母 **2011 年、2021 年两次跳变**（+25.6%、+24.7%）→ 主分析用 count + offset，不用发病率直接建模
- 人口表存在 Excel `#NUM!` 残值 `-2146826273` → 清洗为缺失
- 畜牧业文件名写 2013–2024，**实际数据 2014 起**
- 畜牧表缺值符号为 `\`（4,209 行中 945 处）
- 个案 632 例"病人属于"非本市（本省其它地市 569+其他省 61+外籍 2），**但现住址全部在银川**（74% 在灵武）→ 旧表述"非本市居民"是错的；CSV **无报告日期/诊断日期/感染地点字段**；**用户已拍板放弃"输入性"叙事，M6 删除**
- 2004–2012 有 38 个零病例月 → 月度建模从 2013 起；**2013→2014 病例 168→461（+174%）本身是跳变年，ITS 基线需显式建模**
- 个案止于 2024-12；人口表到 2025（2025 无病例）
- **COVID 混杂**：基线 2019–2021 与疫情防控期重叠，风险表须含 R9（详见交叉审查 P0-2）

## 五之三、设计的四个核心支点（v2.4，不要丢）

1. **新意在"持久性"**——干预撤除后效果是否维持，布病文献完全空白；2025 不论升/平/降都能发（无悔设计）
2. **季节振幅衰减检验 + 分层验证**——无需对照组的机制证据；分层（确诊+本县区归属、分职业）排除"筛查构成稀释季节性"备择解释
3. **暴露梯度分析（非 DID）+ 安慰剂分段点证伪**——替代缺失的平行对照组；n=6 县用 wild cluster bootstrap
4. **"全国在涨（2021–2023）、我们在降"（M13）**——升入正文的外部背景证据
